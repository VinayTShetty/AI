========================================================
LINEAR REGRESSION — COMPLETE EXAMPLE
========================================================

TOPIC:
Salary Prediction using Linear Regression

--------------------------------------------------------
1. DATASET
--------------------------------------------------------

Experience (X)      Salary (Y)
--------------------------------
1                   3
2                   4
3                   5
4                   6
5                   8

Goal:
Predict salary using Linear Regression.

--------------------------------------------------------
2. LINEAR REGRESSION EQUATION
--------------------------------------------------------

y = mx + b

Where:
y = Predicted Output
x = Input
m = Slope
b = Intercept

--------------------------------------------------------
3. FORMULAS
--------------------------------------------------------

Slope Formula:

m = [ N(Σxy) - (Σx)(Σy) ]
    ----------------------
    [ N(Σx²) - (Σx)² ]


Intercept Formula:

b = [ Σy - m(Σx) ]
    ----------------
           N

--------------------------------------------------------
4. CREATE CALCULATION TABLE
--------------------------------------------------------

x       y       x²      xy
--------------------------------
1       3       1       3
2       4       4       8
3       5       9       15
4       6       16      24
5       8       25      40

--------------------------------------------------------
5. CALCULATE SUMS
--------------------------------------------------------

Σx  = 1 + 2 + 3 + 4 + 5
    = 15

Σy  = 3 + 4 + 5 + 6 + 8
    = 26

Σx² = 1 + 4 + 9 + 16 + 25
    = 55

Σxy = 3 + 8 + 15 + 24 + 40
    = 90

N = 5

--------------------------------------------------------
6. CALCULATE SLOPE (m)
--------------------------------------------------------

Formula:

m = [ N(Σxy) - (Σx)(Σy) ]
    ----------------------
    [ N(Σx²) - (Σx)² ]


Substitute values:

m = [ 5(90) - (15)(26) ]
    ---------------------
    [ 5(55) - (15)² ]


Step-by-step:

m = [ 450 - 390 ]
    --------------
    [ 275 - 225 ]

m = 60 / 50

m = 1.2

--------------------------------------------------------
7. CALCULATE INTERCEPT (b)
--------------------------------------------------------

Formula:

b = [ Σy - m(Σx) ]
    ----------------
           N


Substitute values:

b = [ 26 - 1.2(15) ]
    -----------------
           5


Step-by-step:

b = [ 26 - 18 ]
    -------------
         5

b = 8 / 5

b = 1.6

--------------------------------------------------------
8. FINAL LINEAR REGRESSION EQUATION
--------------------------------------------------------

y = 1.2x + 1.6

--------------------------------------------------------
9. PREDICTION
--------------------------------------------------------

Suppose:
Experience = 6 years

Using equation:

y = 1.2x + 1.6

Substitute x = 6

y = 1.2(6) + 1.6

y = 7.2 + 1.6

y = 8.8

Predicted Salary = 8.8 LPA

--------------------------------------------------------
11. COST FUNCTION
--------------------------------------------------------

Cost Function measures prediction error.

Mean Squared Error (MSE):

MSE = (1/N) Σ(y - ŷ)²

Where:
y  = Actual value
ŷ  = Predicted value

--------------------------------------------------------
12. CALCULATE PREDICTED VALUES
--------------------------------------------------------

Equation:

ŷ = 1.2x + 1.6

--------------------------------------------------------
13. ERROR TABLE
--------------------------------------------------------

--------------------------------------------------------

4         6             6.4           -0.4         0.16
5         8             7.6            0.4         0.16

--------------------------------------------------------
14. SUM OF SQUARED ERRORS
--------------------------------------------------------

0.04 + 0 + 0.04 + 0.16 + 0.16

= 0.40

--------------------------------------------------------
15. CALCULATE MSE
--------------------------------------------------------

MSE = 0.40 / 5

MSE = 0.08

Low MSE means:
Model is performing well.
