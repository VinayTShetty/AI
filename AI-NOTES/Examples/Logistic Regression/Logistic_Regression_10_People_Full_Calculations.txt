================================================================================

HOW TO READ THIS FILE
---------------------
- Same 5-step process as Logistic_Regression_Full_Calculations.txt
- 10 training examples (Person A through J)
- 3 input features per person: x1, x2, x3
- learning_rate = 0.1
- Use "End of Round" weights in the NEXT round
- 5 rounds here is only for practice; in real projects you train until
  accuracy/loss stops improving (or use a fixed epoch count you choose)

================================================================================
SECTION A - FORMULAS (USE IN EVERY ROUND)
================================================================================

STEP 1 - SCORE (z)
    z = b0 + (b1 * x1) + (b2 * x2) + (b3 * x3)

STEP 2 - PROBABILITY (p)
    p = 1 / (1 + e^(-z))

STEP 3 - ERROR
    error = p - y

STEP 4 - GRADIENTS (batch of m=10 people)
    grad_b0 = average(error)
    grad_b1 = average(error * x1)
    grad_b2 = average(error * x2)
    grad_b3 = average(error * x3)

STEP 5 - UPDATE WEIGHTS
    new_weight = old_weight - (learning_rate * gradient)
    learning_rate = 0.1

PREDICTION: p > 0.5 -> Yes (1), else No (0)
